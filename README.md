# MYtrans 自動集計ツール

業務システムから出力した `GRID_DATA.CSV` を読み込み、配送ルート別の集計表・配送明細表・未出荷リストを自動作成するPythonツールです。

CSVデータを手作業で並べ替え・集計することなく、日々の配送確認や未出荷確認に使えるExcel帳票を自動作成できます。

---

## 成果物

このツールを実行すると、`MYtrans_output` フォルダ内に以下の3つのExcel帳票が自動作成されます。

| ファイル名              | 内容                              | 用途                |
| ------------------ | ------------------------------- | ----------------- |
| `MYtrans_sum.xlsx` | ルート名・納入先名ごとの受注員数、受注重量の集計表       | ルート別・納入先別の数量・重量確認 |
| `MYtrans_dir.xlsx` | ルート名 → 納入先名 → 受注NO・商品名・受注員数の明細表 | 配送先ごとの明細確認        |
| `未出荷リスト.xlsx`      | 状態が「未出荷」「出荷中」のデータのみを抽出した一覧      | 未出荷・出荷中データの確認     |

出力イメージ：

```text
MYtrans_output/
├─ MYtrans_sum.xlsx
├─ MYtrans_dir.xlsx
└─ 未出荷リスト.xlsx
```

---

## このツールでできること

このツールは、同じフォルダに置いた `GRID_DATA.CSV` を読み込み、以下の処理を自動で行います。

* CSVデータの読み込み
* 列名の表記ゆれ補正
* 受注員数・受注重量の数値変換
* 納入先名の整形
* 状態列の表記統一
* SQLiteへの一時保存
* Excel帳票の自動作成
* A4印刷設定
* Excelが開いている場合の別名保存

## フォルダ構成

`MYtrans.py` または `MYtrans.exe` と同じ場所に、`GRID_DATA.CSV` を置いてください。

```text
MY/
├─ MYtrans.py
├─ GRID_DATA.CSV
└─ MYtrans_output/
   ├─ MYtrans_sum.xlsx
   ├─ MYtrans_dir.xlsx
   └─ 未出荷リスト.xlsx
```

※ `MYtrans_output` フォルダは、実行時に自動作成されます。

---

## 入力ファイルについて

入力ファイル名は、基本的に以下の名前にしてください。

```text
GRID_DATA.CSV
```

必要な列は以下です。

| 必要な列名 | 内容             |
| ----- | -------------- |
| ルート名  | 配送ルート名         |
| 納入先名  | 納入先・得意先・出荷先など  |
| 受注員数  | 数量             |
| 受注重量  | 重量             |
| 状態    | 未出荷・出荷中・出荷済みなど |
| 受注NO  | 受注番号           |
| 商品名   | 商品名            |

---

## 列名の自動変換

CSV側の列名が多少違っていても、コード側で以下のように自動変換します。

| CSV側の列名 | 変換後の列名 |
| ------- | ------ |
| ルート     | ルート名   |
| 配送ルート   | ルート名   |
| ルートコード  | ルート名   |
| 納入先     | 納入先名   |
| 得意先名    | 納入先名   |
| 出荷先名    | 納入先名   |
| 数量      | 受注員数   |
| 員数      | 受注員数   |
| 重量      | 受注重量   |
| 受注ＮＯ    | 受注NO   |

## 実行方法

### Pythonで実行する場合

PowerShellで、`MYtrans.py` があるフォルダに移動します。

例：

```powershell
cd C:\Users\ユーザー名\Desktop\MY
```

その後、以下を実行します。

```powershell
python MYtrans.py
```

または、

```powershell
py MYtrans.py
```

---

### exeで実行する場合

`MYtrans.exe` と `GRID_DATA.CSV` を同じフォルダに置きます。

その後、`MYtrans.exe` をダブルクリック、またはPowerShellから実行します。

## 出力ファイル詳細

### 1. MYtrans_sum.xlsx

ルート名ごと、納入先名ごとの受注員数・受注重量を集計したExcel帳票です。

出力列：

| 列名      | 内容          |
| ------- | ----------- |
| ルート名    | 配送ルート       |
| 納入先名    | 納入先         |
| 合計/受注員数 | 納入先別の受注員数合計 |
| 合計/受注重量 | 納入先別の受注重量合計 |

内容：

* ルート名ごとの合計
* 納入先名ごとの合計
* 最下部に総合計
* 受注重量は小数点以下を四捨五入

印刷設定：

* A4 縦
* 1ページ幅に収まる設定

---

### 2. MYtrans_dir.xlsx

ルート名 → 納入先名 → 受注NO・商品名・受注員数の順に確認できる配送明細帳票です。

出力列：

| 列名   | 内容    |
| ---- | ----- |
| ルート名 | 配送ルート |
| 納入先名 | 納入先   |
| 受注NO | 受注番号  |
| 商品名  | 商品名   |
| 受注員数 | 数量    |

内容：

* ルート名ごとの合計
* 納入先名ごとの合計
* 受注NO、商品名、受注員数の明細

印刷設定：

* A4 横
* 1ページ幅に収まる設定

---

### 3. 未出荷リスト.xlsx

状態が「未出荷」「出荷中」のデータだけを抽出したExcel帳票です。

出力列：

| 列名   | 内容      |
| ---- | ------- |
| 状態   | 未出荷・出荷中 |
| 納入先名 | 納入先     |
| 受注NO | 受注番号    |
| 商品名  | 商品名     |
| 受注員数 | 数量      |

抽出条件：

* 状態が「未出荷」
* 状態が「出荷中」

印刷設定：

* A4 横
* 1ページ幅に収まる設定

## 工夫した点

このツールでは、現場で使いやすいように以下の点を工夫しています。

* CSVの文字コード違いに対応
* カンマ区切り・タブ区切りの判定に対応
* 拡張子がCSVでも中身がExcel形式の場合に対応
* 列名の表記ゆれに対応
* 納入先名の不要な括弧情報を削除
* 状態の表記ゆれを統一
* 数量・重量のカンマやkg表記を除去して数値化
* 作業用データをSQLiteに一時保存
* Excel帳票の列幅・折り返し・罫線を自動設定
* A4印刷設定を自動設定
* 出力Excelが開いている場合は、時刻付きの別名ファイルとして保存

## 注意点

### 1. GRID_DATA.CSV の配置場所

`GRID_DATA.CSV` は、`MYtrans.py` または `MYtrans.exe` と同じフォルダに置いてください。

---

### 2. Excelファイルを開いたまま実行しない

出力先のExcelファイルを開いたまま実行すると、上書き保存できない場合があります。

その場合は、自動で時刻付きの別名ファイルとして保存されます。

例：

```text
MYtrans_sum_153012.xlsx
```

---

### 3. CSVの中身がExcel形式の場合

`GRID_DATA.CSV` の拡張子が `.CSV` でも、中身がExcel形式の場合があります。

Excelで開いた時に、

```text
ファイル形式と拡張子が一致しません
```

と表示される場合は、Excelで開いた後に以下の形式で保存し直してください。

```text
CSV UTF-8（コンマ区切り） (*.csv)
```

---

### 4. 業務データはGitHubに上げない

`GRID_DATA.CSV` には、納入先名・受注NO・商品名などの業務データが含まれる可能性があります。

そのため、GitHubにはアップロードしないようにしてください。

## よくあるエラー

### CSVファイルが見つかりません

原因：

`GRID_DATA.CSV` が `MYtrans.py` / `MYtrans.exe` と同じフォルダにありません。

対処：

`GRID_DATA.CSV` を同じフォルダに置いてください。

---

### ルート名列がありません

原因：

CSV内の列名が、コードで想定している列名と違います。

対処：

CSVの列名を確認し、必要であればコード内の `normalize_columns()` に変換ルールを追加してください。

---

### 受注重量列がありません

原因：

CSVに「受注重量」または「重量」に該当する列がありません。

対処：

元データ側の列名を確認してください。

---

### Excelファイルが開いていて保存できない

原因：

出力先のExcelを開いたまま実行しています。

対処：

Excelを閉じてから再実行してください。

または、自動で時刻付きの別名ファイルが作成されます。

---

## exe化する場合

PyInstallerを使う場合は、以下のコマンドを実行します。

```powershell
pyinstaller --onefile MYtrans.py
```

`dist` フォルダ内に `MYtrans.exe` が作成されます。

exe化後は、`MYtrans.exe` と `GRID_DATA.CSV` を同じフォルダに置いて実行してください。

---

## .gitignore について

以下のファイルやフォルダは、GitHubにアップロードしないことを推奨します。

```text
GRID_DATA.CSV
MYtrans_output/
*.xlsx
*.db
dist/
build/
__pycache__/
```

特に `GRID_DATA.CSV` や出力Excelには業務データが含まれる可能性があるため、管理対象から外してください。

---

## 運用手順

毎回の基本手順は以下です。

1. 業務システムからデータを出力する
2. ファイル名を `GRID_DATA.CSV` にする
3. `MYtrans.py` または `MYtrans.exe` と同じフォルダに置く
4. `MYtrans.py` または `MYtrans.exe` を実行する
5. `MYtrans_output` フォルダ内のExcelを確認する
6. 必要に応じて印刷・コピーする
